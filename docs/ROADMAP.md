# Balaji AI Workbench: Learning & Building Roadmap

This roadmap breaks down your 6 objectives into progressive, manageable phases. You can check off items as you complete them.

---

## 🏁 Phase 1: Foundations & Quick Wins (No Coding Required)
- [x] **1.1 Agile Hub:** Add your favorite retrospective templates (Sailboat, 4Ls) in `01_agile_hub/templates/`.
- [x] **1.2 Prompt Library:** Create a prompt template in `01_agile_hub/prompts/` to rewrite user stories into INVEST format.
- [x] **1.3 STAR Story Bank:** Create your personal STAR story repository in `02_career_and_communication/interview_prep/`.
- [x] **1.4 Executive Polisher:** Save a prompt in `02_career_and_communication/business_english/` to convert rough thoughts into professional stakeholder emails.

---

## ⚡ Phase 2: First Automations & Custom AI Personas
- [x] **2.1 Meeting Action Items Extractor:** Build a prompt/script in `03_automations/meeting_assistants/` that converts raw meeting notes into action items.
- [x] **2.2 Custom Scrum Coach Agent:** Configure an Agile Coach persona in `05_agents_and_skills/agents/` that provides objective feedback on sprint dilemmas.
- [x] **2.3 Mock Interviewer Agent:** Configure an AI interviewer persona in `05_agents_and_skills/agents/` to simulate behavioral and Scrum Master interview questions.

---

## 🐍 Phase 3: Beginner Coding & API Basics
- [ ] **3.1 Python First Steps:** Complete basic exercises in `06_learning_lab/python_basics/` (variables, loops, functions).
- [ ] **3.2 File Automation:** Write a Python script to read a CSV of team metrics and summarize averages.
- [ ] **3.3 First API Call:** Run a basic script in `06_learning_lab/api_playground/` calling the Gemini API to summarize text.
- [ ] **3.4 Secrets Management:** Learn how `.env` works to store API tokens safely without hardcoding them in scripts.

---

## 📊 Phase 4: Interactive Apps & Visual Dashboards
- [ ] **4.1 Streamlit Hello World:** Set up a lightweight Streamlit app in `04_apps_and_dashboards/sprint_dashboard/`.
- [ ] **4.2 Sprint Health Visualizer:** Display sprint burndown charts or team velocity in an interactive web browser dashboard.
- [ ] **4.3 Team Retro Voting App:** Build an interactive widget to collect team feedback.

---

## 🚀 Phase 5: Advanced AI, MCP & Reusable Skills
- [ ] **5.1 MCP Exploration:** Connect an MCP server (e.g., Jira, Google Drive, or SQLite) in `06_learning_lab/mcp_experiments/`.
- [ ] **5.2 Custom Antigravity Skill:** Package your meeting summary workflow as a native reusable skill (`SKILL.md`) in `05_agents_and_skills/skills/`.
- [ ] **5.3 End-to-End Workflow:** Run an automated pipeline that pulls sprint updates, summarizes them, and sends a formatted digest.
